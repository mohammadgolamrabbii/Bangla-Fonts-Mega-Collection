## 📁 ফোল্ডার সংগঠন (Folder Structure)

```text
Bangla-Fonts-Collection/
├── 1_Unicode/ (১,৩২৯টি ফন্ট)
│   ├── লিপিঘর (Lipighor) এর সম্পূর্ণ Li Alinur ও ডিজাইনার সিরিজ
│   ├── সম্পূর্ণ Google Fonts Bengali (Hind Siliguri, Baloo Da 2, Anek Bangla, Tiro, Mina ইত্যাদি)
│   ├── অমিক্রনল্যাব ও অভ্র কিবোর্ড ফন্টস (Kalpurush, SolaimanLipi, Siyam Rupali ইত্যাদি)
│   ├── একুশে ও ওপেনবাংলা ফন্টস (AdorshoLipi, Nikosh, Sagar, Mukti ইত্যাদি)
│   └── আধুনিক বইয়ের প্রচ্ছদ, ব্যানার, পোস্টার ও ইউটিউব থাম্বনেইলের ক্যালিগ্রাফি ফন্ট
│
└── 2_Bijoy_ANSI/ (১,২৫০টি ফন্ট)
    ├── সকল ক্লাসিক SutonnyMJ ও এর সকল ভ্যারিয়েন্ট (Bold, Italic, Condensed)
    ├── আনন্দ, আত্রাই, ভৈরব, বংশী, চন্দ্রাবতী ও অন্যান্য ক্লাসিক প্রেস ফন্ট
    └── অ্যাডোবি ফটোশপ ও ইলাস্ট্রেটরে বিজয় কিবোর্ডের জন্য স্টাইলাইজড ANSI ফন্টসমূহ
```

## 💻 উইন্ডোজে ইনস্টল করার পদ্ধতি (How to Install)

1. রিপোজিটরির সবুজ **Code** বাটনে ক্লিক করে **Download ZIP** চাপুন অথবা গিট ক্লোন করুন:
   ```bash
   git clone https://github.com/mohammadgolamrabbii/Bangla-Fonts-Mega-Collection.git
   ```
2. ডাউনলোড করা ফাইলটি আনজিপ করুন।
3. ফোল্ডারের ভেতরে গিয়ে যেকোনো ফন্ট বা একসাথে সব ফন্ট সিলেক্ট করে মাউসের ডান ক্লিক (`Right Click`) করুন।
4. **Install for all users** (অথবা **Install**) অপশনটিতে ক্লিক করুন। ব্যস, ফন্টগুলো কম্পিউটারে ইনস্টল হয়ে যাবে!
